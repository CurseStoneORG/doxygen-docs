Detailed Description

A resolved snapshot of a player or mob a goal tracks.

The era code held TempEPtr smart references across ticks; CurseStone identifies targets by eid and refreshes the snapshot through Mob::resolve() at every use, so a removed victim degrades to an empty reference instead of a dangling pointer.
