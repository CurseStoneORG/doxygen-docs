24 // MobAIManager — the per-world driver of the mob AI pass (docs/MOB_AI.md).
25 // Owned by its World and drained from World::tick(), it runs entirely on
26 // the main thread inside a wall-clock budget. The stage-2 pass is tiered:
27 // mobs near players get full physics every tick, mobs at the edge of the
28 // view distance update on a reduced cadence, and chunks with no player in
29 // range are never even visited (their records stay persisted in the
30 // region files). The actuation step converts brain intent into
31 // physics::sweep() moves and World::moveMob() broadcasts, with obstacle
32 // steering, the panic reflex, the half-submerged swim model and the
33 // water splash effects riding on top.

74  // ---- Tier contract (docs/MOB_AI.md section 5) ----
75  // FULL chunk within kFullTierRadius of a player: think on the
76  // staggered cadence, actuate every tick.
77  // REDUCED within the view distance but beyond that radius:
78  // think on a longer cadence, actuate every kReducedInterval
79  // ticks (the stride per actuation is unchanged, so positions
80  // stay exact — packets just arrive at 5 Hz, which is what
81  // vanilla does to far entities anyway).
82  // FROZEN outside every player's view distance: the chunk is not
83  // visited at all; the record persists in the region files.
