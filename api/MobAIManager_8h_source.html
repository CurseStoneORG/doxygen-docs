24 // MobAIManager — the per-world driver of the mob AI pass (docs/MOB_AI.md).
25 // Owned by its World and drained from World::tick(), it runs entirely on
26 // the main thread inside a wall-clock budget. The pass is tiered: mobs
27 // near players run the full era pipeline every tick (MobBrain::
28 // newServerAiStep + actuation), mobs at the edge of the view distance
29 // update on a reduced cadence, and chunks with no player in range are
30 // never visited (their records stay persisted in the region files).
31 // The actuation step converts the era control state — movement yaw,
32 // speed channel, jumping — into physics::sweep() moves and
33 // World::moveMob() broadcasts, with the water splash effects riding on
34 // top.

67  // ---- Tier contract ----
68  // FULL chunk within kFullTierRadius of a player: the full era
69  // pipeline (goals + controls + actuation) every tick.
70  // REDUCED within the view distance but beyond that radius: the same
71  // pipeline every kReducedInterval ticks (the stride per
72  // actuation is unchanged, so positions stay exact — packets
73  // just arrive at 5 Hz, which is what vanilla does to far
74  // entities anyway).
75  // FROZEN outside every player's view distance: the chunk is not
76  // visited at all; the record persists in the region files.
77  static constexpr int32_t kFullTierRadius = 4;
78  static constexpr uint64_t kReducedInterval = 4;
