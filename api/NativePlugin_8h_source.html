24 // NativePlugin — a plugin shipped as a BARE shared library file dropped
25 // directly into plugins/ (.so on Linux/Android/macOS, .dll on Windows):
26 // no folder, no plugin.yml. The library implements the C ABI from
27 // NativeAPI.h and its vtable descriptor (name / version / author / api)
28 // IS the manifest.
29 //
30 // IDENTITY: the file stem (HelloNative from HelloNative.so) owns the
31 // data_pl/<stem> folder and doubles as the fallback display name; the
32 // descriptor name wins for display when it differs. Uniqueness rules are
33 // enforced by PluginManager (duplicate stems and duplicate descriptor
34 // names both disable the copies involved).
35 //
36 // LIFECYCLE: load() opens the library (dlopen / LoadLibrary), validates
37 // the vtable ABI version, checks the descriptor's `api` claim against
38 // CURSESTONE_API and calls onLoad with the plugin's CsPluginApi.
39 // enable()/disable()/dtor drive onEnable / onDisable / onUnload the same
40 // way LuaPlugin drives its hooks.
41 //
42 // SAFETY: the library is opened with RTLD_LOCAL so plugins stay symbol-
43 // isolated from each other; every plugin callback is wrapped in
44 // catch(...) so a throwing callback is logged instead of unwinding into
45 // the server. The ABI version check plus the reload-safe command bridge
46 // (see NativeCommand) protect against stale function pointers.
