Detailed Description

One floating-text snapshot with the Genisys tag pair separated: title (top line) and text (body) travel on the wire joined as "title\nbody"; follow is the entity id the tag anchors over (0 = static) and viewers the armed player count.

Both strings are NUL-terminated and truncate at capacity.
