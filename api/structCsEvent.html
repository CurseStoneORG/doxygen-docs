Detailed Description

Event snapshot passed to native listeners.

One struct for every supported event: fields that do not apply to the current event keep their zero value (strings are "", doubles are 0). Three fields are WRITABLE by the listener: message (join/quit/chat/ death — the server reads it back), amount (damage events, >= 0) and cancelled (only honoured by cancellable event types).
