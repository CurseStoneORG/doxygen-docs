Detailed Description

A persistent, multi-line floating text rendered through invisible client-side carriers, owned by the world like every other particle.

The text model is a list of lines: line 0 is the title carried by the entity id the world hands out, lines 1..n are body carriers rendered below it. The class tracks which players currently render the text and reconciles that set with the chunk-based audience every second, so a player that joins or walks into range receives the text exactly like a player that was in range at spawn time.

'
' splits it into lines: the first line is the title, every following line is a body carrier.

The change is diffed per line: only lines whose text moved emit one SetEntityDataPacket to the active viewers, extra lines despawn, missing lines spawn. Lines are clamped to kMaxLines and kMaxLineChars.
