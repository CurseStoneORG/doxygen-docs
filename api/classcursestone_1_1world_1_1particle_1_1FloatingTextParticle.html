Detailed Description

A persistent floating text rendered through one invisible client-side fake player, owned by the world like every other particle.

The text model is the Genisys tag pair: title is the top line (the carrier username on the wire) and text is the body, whose '
' lines the client stacks below the title. The class tracks which players currently render the text and reconciles that set with the chunk-based audience every second, so a player that joins, walks into range or returns from another world receives the text exactly like a player that was in range at spawn time.
