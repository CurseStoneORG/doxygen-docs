Detailed Description

One behavior of a mob brain.

A goal object is owned by exactly one MobBrain and may keep its own state between evaluations (wander targets, timers). Selection runs on the mob's think cadence: goals with a higher priority() win flag conflicts, canStart() gates activation, shouldContinue() decides when to release.
