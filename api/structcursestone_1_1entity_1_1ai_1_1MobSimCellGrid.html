Detailed Description

Immutable 3x3 (XZ) x 4-row (Y) block window around a mob's feet cell.

Covers every cell the steering probes and the step-up checks can read for ANY intent direction: a probe lands at floor(x + dx * 0.6), which stays inside the anchor's +/-1 neighborhood, and the probe rows are feet-1 .. feet+2. Out-of-window reads answer air (0) — the window is sized so no in-range probe ever misses it.
