24 // server — singleton. Mirrors pocketmine/server.php.
25 //
26 // Responsibilities:
27 // 1. Boot: load cursestone.yml, init logger, register blocks/items,
28 // create CommandMap + register default commands, create the
29 // default World (overworld), open the RakLibInterface.
30 // 2. tick (every 50ms): advance scheduler, tick world(s), tick
31 // players, drain RakLib→main FIFO, advance time.
32 // 3. Shutdown: disconnect all players, save world(s), close network.
33 //
34 // player roster + broadcasting:
35 // - players() returns the list of online Players (read-only).
36 // - broadcastMessage() sends to TextPacket to every player.
37 // - removePlayer() unregisters to closed player.
38 //
39 // Command processing:
40 // - console input via CommandReader thread → SimpleCommandMap::dispatch.
41 // - player chat /slash via player::handleChat → SimpleCommandMap::dispatch.

262  // --- Autosave incremental ---
263  // The autosave does NOT write the world in one go. The autosave tick
264  // (every autosave_ticks_) saves the cheap data (player data +
265  // level.dat) and opens the drain; from then on each tick writes to few
266  // dirty chunks until the queue is empty. to full world_->save() in to
267  // single tick used to block the main thread for ~500-760 ms
268  // (measured) with to loaded world - the same freeze to live client
269  // ends up reading as to disconnect, the one behind the warning
270  // "[SAVE] Autosave took 759ms — this may cause disconnects!".
271  // Per-tick cost is bounded by kAutosaveChunksPerTick /
272  // kAutosaveMsPerTick.
273  void beginAutosaveDrain();
274  void tickAutosaveDrain();
