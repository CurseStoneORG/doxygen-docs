24 // NativeAPI — the C ABI contract between CurseStone and NATIVE plugins
25 // (.so on Linux/Android/macOS, .dll on Windows).
26 //
27 // A native plugin is a shared library that exports ONE symbol:
28 //
29 // const CsPluginVTable* CurseStonePlugin_entry(void);
30 //
31 // The vtable carries the plugin descriptor plus its lifecycle hooks
32 // (onLoad / onEnable / onDisable / onUnload; only desc and onLoad are
33 // required). Everything the plugin can do goes through the CsPluginApi
34 // pointer handed to onLoad: plain C function-pointer groups, so plugins
35 // compile against ONLY this header and never link against the server
36 // binary. That keeps the ABI stable across builds and lets one .so work
37 // on any server built from the same SDK revision.
38 //
39 // RULES FOR PLUGIN AUTHORS:
40 // - Threading: every callback (events, tasks, commands) runs on the
41 // main thread, in the tick it was queued. Never block in a callback.
42 // - Lifetime: strings handed OUT by the API (event fields, argv,
43 // CsCommandSender::name) are owned by the server and are only valid
44 // until the callback returns. Buffers the plugin fills (char* out,
45 // uint32_t cap) are always caller-owned.
46 // - The CsPluginApi pointer received in onLoad must be passed back as
47 // the first argument of every context-bound call (log.*, scheduler.*,
48 // commands.*, events.*, data.*). Context-free groups (server.*,
49 // player.*, world.*) never take it.
50 // - A plugin callback must not call into the server after its own
51 // onDisable has run: the server removes listeners, tasks and
52 // commands before unloading the library.
53 //
54 // COMPATIBILITY: bumping CS_PLUGIN_ABI_VERSION means the struct layouts
55 // below changed in an incompatible way; the server rejects plugins whose
56 // vtable reports a different version. Appending to a group struct is a
57 // breaking change too (size changes are not versioned per-group) — the
58 // agreed workflow is: extend in place, keep field order, bump the ABI
59 // version, and keep the CURSESTONE_API string untouched until release.
