Detailed Description

World queries.

First argument is the world name; the call fails (0 / false) for worlds that are not loaded.

◆ spawnEntity

int64_t(* CsWorldApi::spawnEntity) (const char *world, int32_t type, double x, double y, double z, float yaw, float pitch)

Spawns one standing mob (no AI, no physics, zero per-tick cost).

type is a protocol-84 network id from entityTypeFromName(); ids outside the registry fail because the 0.15.10 client has no verified renderer for them.

Parameters
yfeet position; yaw/pitch spawn rotation.
Returns
the entity id for move/remove/get, or -1 for an invalid type/position or at the per-world cap (256/world).

◆ spawnFloatingText

int64_t(* CsWorldApi::spawnFloatingText) (const char *world, double x, double y, double z, const char *text, int32_t ttlTicks)

Spawns a floating text: an invisible fake-player carrier whose only visible part is its nametag (protocol 84 has no text particle and this client era draws nametags only on player entities).

'
' splits the title line from the body lines the client stacks. One spawn pair, zero per-tick cost.

Parameters
ttlTicks> 0 despawns automatically after that many ticks; 0 keeps it until removeFloatingText(). Entity ids do not survive server restarts.
Returns
the entity id for move/remove, or -1 at the per-world cap.
