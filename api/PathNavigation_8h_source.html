24 // PathNavigation — the bridge between the goals and MoveControl.
25 //
26 // Port of <minecraftpe/impl/entity/path/PathNavigation.cpp> (MCPE 0.8.1
27 // decompile). Goals call moveTo(entity/position, speed); tick() skips
28 // the path ahead while the body rides it, feeds the current cell into
29 // MoveControl::setWantedPosition, and abandons a path that made no
30 // progress for 100 ticks.
31 //
32 // Adaptations for the server (behavior-preserving, cost-saving):
33 // - the full A* re-run a moveTo request triggers is rate-limited: a
34 // re-path only happens when the path is gone or finished, the goal
35 // moved more than 1.5 blocks from the last computed target, or the
36 // path aged past kRepathTicks (the era re-pathed on every request;
37 // the goals themselves re-request every few ticks, which on a
38 // server-sized population turns A* into the dominant AI cost);
39 // - the canMoveDirectly shortcut (era PathNavigation::canMoveDirectly)
40 // stays: a straight-line walkable segment lets the path index jump
41 // ahead.
