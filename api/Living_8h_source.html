36 // Result of a damage() or damageByEntity() call.
37 // CANCELLED: No damage was applied because the entity was dead, immune, or the event was cancelled.
38 // HURT: Damage was applied, and the entity survived.
39 // KILLED: Damage was applied, and the entity died.
40 // Callers use this result to determine whether to synchronize the hit with clients.
41 // CANCELLED hits send no packets, health updates, or knockback.
42 
43 enum class DamageApply {
44  CANCELLED = 0,
45  HURT = 1,
46  KILLED = 2,
47 };
