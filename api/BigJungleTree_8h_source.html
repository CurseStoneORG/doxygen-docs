24 // BigJungleTree — the vanilla "big jungle tree": a very tall buttressed
25 // trunk, horizontal branches each capped with its own leaf cluster, a
26 // layered crown, and vines hanging off the wood.
27 //
28 // Ported 1:1 from Aquamarine-Team/Aquamarine
29 // (src/world/generator/normal/object/BigJungleTree.php, by MaruselPlay),
30 // which is itself the PocketMine-MP HugeTree algorithm. The PHP hierarchy is
31 // flattened into this one class because CurseStone's tree base
32 // (GenericTree) is not a HugeTree:
33 //
34 // * getHeight() -> init() sets height_ from kBaseHeight +
35 // rng[0, kExtraRandom-1]
36 // * ensureGrowable() -> the room/soil checks GenericTree::generate
37 // already does, done up front here
38 // * canOverride() -> canOverrideAt()
39 // * growLeavesLayer() -> growLeavesLayer()
40 // * growLeavesLayerStrict() -> growLeavesLayerStrict()
41 // * setBlockAndNotifyAdequately() -> GenericTree::setForced() (writes
42 // unconditionally, clipped to the chunk)
43 // * placeVine() -> placeVine()
44 //
45 // Two deliberate, documented deviations from the PHP:
46 // 1. The reference passes plain Block::LOG / Block::LEAVES with no
47 // metadata. CurseStone's protocol stores the wood/leaf VARIANT in the
48 // block data byte, so this uses data 3 (jungle) — the same pair
49 // JungleTree uses — otherwise the client would draw an oak tree.
50 // 2. The reference's first pair of assignments inside the branch loop
51 // (0.5 + cos*f*4.0) is dead: the inner i1 loop overwrites $k/$l before
52 // anything reads them. It is dropped here; the value it computed is
53 // unchanged.

55 #include "GenericTree.h"
