◆ collect()

void cursestone::MemoryManager::collect ( bool  force = false)

Runs one coordinated global collection pass.

Everything else must call this. "force" runs the full sweep immediately (shutdown, /save, tests); otherwise the pass is rate-limited by gc_interval_ticks_ so the world can never be swept mid-tick by several unrelated callers. Runs on the main thread only (all world registries are main-thread or guarded there).

Parameters
forcebypass the interval gate but never the single-entry exclusivity of a pass.

bool cursestone::MemoryManager::shouldGc ( ) const

Reports whether RSS exceeds the configured budget.

Cheap enough to be polled; the decision to actually collect is made by collect(). A non-positive limit disables the check.

Returns
true when the budget is exceeded and collection may run.
