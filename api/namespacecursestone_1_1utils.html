Detailed Description

Loads the server config file (YAML / INI / JSON).

Wraps a semantic version string.

Provides the C++ helpers on top of the C Utils interface.

Wraps the C mcp_main_logger_t as a C++ singleton.

Implements a minimal subset of YAML (nested maps, lists, scalars, comments) sufficient to parse cursestone.yml. For full YAML support, future phases may vendor yaml-cpp.

Exposes utils::MainLogger::get().info/warn/error/debug(string). All C++ files that log should include this; C files include MainLogger.h.

Include this in C++ files; C files include utils/Utils.h.

Used by the Server and by plugin manifests.
