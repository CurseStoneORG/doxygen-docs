24 // Target goals — TargetGoal, HurtByTargetGoal, NearestAttackableTargetGoal.
25 //
26 // The MCPE 0.8.1 decompile ships these three as empty bodies (the
27 // includes survive, the implementations were lost with the inline
28 // expansion). The era contract is known from the call sites: they run in
29 // the second selector (Mob::goalSelector2, ticked before the movement
30 // selector), claim no control flags, and write the mob's attack target
31 // that the combat goals read back through Mob::getTarget(). The bodies
32 // here reconstruct the era behavior:
33 // - HurtByTargetGoal: retaliate against the last attacker.
34 // - NearestAttackableTargetGoal: acquire the nearest player within the
35 // follow range (16 blocks, the value every era mob registers).
36 // Both keep their target while it stays alive and in range, and clear it
37 // on stop (the era Mob cleared the attack target when the goal released).
