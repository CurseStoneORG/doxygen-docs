24 // MobSimCompute — the pure plan functions of the stage-3 parallel mob
25 // simulation (docs/MOB_AI.md section 9). Each stage moves one slice of
26 // the actuation pipeline off the main thread:
27 //
28 // 3.2 kOffThink — the goal think pass (planThink).
29 // 3.3 kOffSteer — obstacle steering + facing (planSteer).
30 // 3.4 kOffPhysics — vertical model, stride and the collision sweep
31 // (planPhysics), against the box set the main
32 // thread collected after fence A.
33 //
34 // Every function here is world-free: it reads the immutable input
35 // snapshot and the worker's shadow brain, and writes pure output
36 // values. The main thread stays the only component that mutates the
37 // World (moveMob, particles, sprint bit). plan* functions produce the
38 // SAME numbers the sequential actuateOne produces from the same state
39 // — the gate mode proves it per mob per tick, and the parallel check
40 // harness proves it bit-exact on synthetic frames.

79 inline float yawDelta(float a, float b) {
80  float d = a - b;
81  while (d > 180.0f)
82  d -= 360.0f;
83  while (d < -180.0f)
84  d += 360.0f;
85  return std::fabs(d);
86 }
