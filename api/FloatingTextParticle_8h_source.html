23 // FloatingTextParticle — the protocol-84 floating text particle.
24 //
25 // The 0.15.10 client draws nametags only on player entities, so one
26 // floating text is one invisible fake player: the carrier spawns through
27 // AddPlayerPacket and takes its wire face from a SetEntityDataPacket
28 // (invisible flag, nametag, NoAI) — the same two-packet spawn every real
29 // player of this server uses. The text model is the Genisys tag pair:
30 // a TITLE line riding the carrier username plus a BODY the client stacks
31 // below it, so a text costs one entity and one fixed spawn pair no matter
32 // how many lines it carries.
33 //
34 // The particle supports the five tag shapes the protocol can express:
35 // static fixed anchor position (the default)
36 // follow anchors over one entity or player every tick it moves
37 // filtered only the players of an allow list render it
38 // hidden exists but despawned until shown again (visibility toggle)
39 // expiring despawns after a TTL (driven by World's scheduler)
40 //
41 // Performance contract: every wire packet is cached per text and shared
42 // by every viewer — a re-text emits one SetEntityDataPacket, a move emits
43 // one MovePlayerPacket (the spawn face is rebuilt lazily, only when the
44 // next viewer needs it), viewer churn (joins, walk-ins, walk-outs, world
45 // switches) reconciles in one pass per second, follow texts reposition at
46 // most once per moved target per tick, and a world without floating
47 // texts pays nothing.

88 class FloatingTextParticle {
89  public:
90  // Ticks between viewer reconciliations (one second at 20 TPS).
91  static constexpr uint64_t kViewerSyncTicks = 20;
92  // The carrier body hangs this far below the text line: the invisible
93  // player stands 1.62 (the era eye height) under the requested y, so
94  // the nametag anchor renders at the requested spot and the body-sized
95  // hitbox stays clear of it.
96  static constexpr float kCarrierDrop = 1.62f;
97  // Follow mode anchors the text line this far above the target's feet:
98  // just above a player's own head (1.8), so the tag never overlaps the
99  // target's nametag.
100  static constexpr float kFollowLift = 2.1f;
101  // Follow mode resends the carrier move only past this distance from
102  // the last sent position — a target moving under it costs zero wire.
103  static constexpr float kFollowThreshold = 0.15f;
104  // Whole-text wire ceiling (title + '\n' body lines together).
105  static constexpr size_t kMaxTextChars = 512;
106  // Title-only ceiling; the body absorbs whatever the pair leaves.
107  static constexpr size_t kMaxTitleChars = 128;
