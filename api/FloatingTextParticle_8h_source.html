24 // FloatingTextParticle — the protocol-84 floating text particle.
25 //
26 // The 0.15.10 client draws nametags only on player entities, so one
27 // floating text is one invisible fake player: the carrier spawns through
28 // AddPlayerPacket and takes its wire face from a SetEntityDataPacket
29 // (invisible flag, nametag, NoAI) — the same two-packet spawn every real
30 // player of this server uses. The whole text, title and every '\n' body
31 // line, rides on that single nametag; the client stacks the lines itself,
32 // so a text costs one entity and one fixed spawn pair no matter how many
33 // lines it carries.
34 //
35 // Performance contract: the spawn pair and the removal packet are built
36 // once per text and reused by every viewer; a re-text emits one
37 // SetEntityDataPacket; a move emits one MovePlayerPacket; viewer churn
38 // (joins, walk-ins, walk-outs, world switches) reconciles in one pass per
39 // second; a world without floating texts pays nothing.
