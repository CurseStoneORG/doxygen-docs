24 // FloatingTextParticle — the protocol-84 floating text particle.
25 //
26 // Protocol 84 has no text-rendering particle; floating text rides on
27 // client-side item entities (type 64, item 0): the client draws nothing
28 // but the nametag above an invisible carrier. One text is a small packet
29 // composite: the first line is the nametag of the carrier entity, every
30 // following line gets its own carrier one line slot below it.
31 //
32 // Performance contract: one prebuilt AddEntityPacket per line, reused by
33 // every viewer; a re-text emits one SetEntityDataPacket per changed line
34 // only; viewer churn (joins, walk-ins, walk-outs) reconciles in one pass
35 // per second; a world without floating texts pays nothing.
