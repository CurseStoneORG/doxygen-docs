24 // Mob — the AI-layer facade the ported MCPE 0.8.1 code operates on.
25 //
26 // The era decompile drives real Mob entity objects (posX, yaw, headYaw,
27 // boundingBox, level, random ...). CurseStone mobs are plain
28 // world::MobEntity records driven by MobAIManager, so this facade
29 // reproduces the era Mob surface on top of the record plus the per-mob
30 // dynamic state the brain owns. One Mob object lives inside its
31 // MobBrain; bind() attaches it to the record being simulated this tick.
32 //
33 // Yaw convention: all angles are the protocol-84 entity yaw the server
34 // already broadcasts (0 = +Z, 90 = +X; direction = (sin, cos)). See
35 // AiMath.h for the era conversion note.

79  double distanceToSqr(double px, double py, double pz) const {
80  const double dx = px - x, dy = py - y, dz = pz - z;
81  return dx * dx + dy * dy + dz * dz;
