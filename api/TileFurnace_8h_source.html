23 // TileFurnace — furnace block entity. 3 slots: input, fuel, output.
24 // Burns fuel at 1 tick per 10 ticks; smelting progress at 1 tick
25 // per 200 ticks. The state of the burn/cook progress is sent to
26 // clients via ContainerSetDataPacket.
27 //
28 // Implementación completa (the reference server Tile/Furnace):
29 // - tick() avanza burn_time_/cook_time_, consume 1 input por
30 // fundición completa, consume fuel cuando se acaba el burn y
31 // escribe el resultado en el slot 2.
32 // - El progreso se transmite SOLO a los jugadores con el horno
33 // abierto (ContainerSetDataPacket property 0/1, escala 0..200).
34 // - Persistencia NBT legacy de Nukkit: { BurnDuration, BurnTicks,
35 // CookTicks, Items: [{Slot,id,Damage,Count}] }.

117  bool lit_ = false; // el bloque ya está en BURNING_FURNACE
118  std::vector<void*> viewers_; // Player* crudos, NO desreferenciar (solo comparar)
