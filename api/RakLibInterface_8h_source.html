24 // RakLibInterface — C++ wrapper around the C raklib/RakLibServer.
25 //
26 // ARCHITECTURE: RakLib runs on its OWN THREAD (raklib_thread_) at
27 // ~100Hz (10ms sleep). It processes UDP recv/send, keepalives,
28 // ACKs/NACKs, retransmits and timeouts independently of the main
29 // tick loop.
30 //
31 // Two thread-safe FIFO queues bridge RakLib ↔ main thread:
32 // inbound_queue_ (RakLib → main): received packets + session events
33 // outbound_queue_ (main → RakLib): packets to send + session closes
34 //
35 // The main thread drains inbound_queue_ in Network::tick(), processes
36 // packets, then posts any responses to outbound_queue_. The RakLib
37 // thread drains outbound_queue_ before each mcp_raklib_server_tick().
38 //
39 // This mirrors PMMP's RakLibServer (which extends Thread) and
40 // communicates via ThreadSafeArray.
