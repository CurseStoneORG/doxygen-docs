23 // BlockMining — vanilla mining rules per block id. Mirrors the Java
24 // hardness / tool-class / harvest-tier tables the 0.15 client mirrors:
25 //
26 // breakSeconds = hardness * (canHarvest ? 1.5 : 5.0) / toolSpeed
27 //
28 // where toolSpeed applies only when the held tool's class matches the
29 // block's class (wood 2, gold 12, stone 4, iron 6, diamond 8) and the
30 // 5x penalty only bites tool-gated blocks (stone never yields to a hand,
31 // dirt does). `miningRule` is a jump-table switch — O(1) with no data
32 // segment; unlisted ids fall back to generic hand-harvestable stone.

42 // tool: item::ToolType the block mines faster with (PICKAXE=0, AXE=1,
43 // SHOVEL=2); T_NONE when no tool class applies. tier: -1 when the block
44 // is NOT tool-gated (drops by hand, the tool only speeds it up); >= 0 is
45 // the minimum harvest level the held tool must reach for a drop
46 // (wood/gold 0, stone 1, iron 2, diamond 3).
47 constexpr int8_t T_NONE = -1;

49 struct BlockMiningRule {
