Detailed Description

Flees from the threat that just landed a hit.

Passive-only: the manager stamps every hit's away-from-damager direction into the mob record from the damage pipeline (any thread), and this goal reads it through the context snapshot. Claims MOVE at a priority above Wander, so a mob that was strolling when struck bolts instead — and keeps running for kPanicTicks after the last hit, re-aimed every so often so it does not run in a straight line into a wall.
