Detailed Description

Cross-platform mutex, condition variable and thread handle.

POSIX maps 1:1 onto pthreads; Windows/MSVC maps onto Win32 CRITICAL_SECTION + CONDITION_VARIABLE + CreateThread, so no pthread header or symbol ever reaches an MSVC translation unit.

Recursive-usage-safe mutual exclusion lock.
