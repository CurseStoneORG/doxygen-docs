Detailed Description

Per-plugin data folder (data_pl/<plugin>), same sandbox the Lua data.

  • API uses: relative paths only, no "..", no backslashes.

readFile() returns a server-allocated buffer the plugin releases with free(); list() joins entry names with '
' and returns how many fit.
