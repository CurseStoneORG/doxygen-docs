Detailed Description

Root API handed to CurseStonePlugin_vtable's onLoad hook.

Group pointers stay valid for the whole plugin lifetime. apiSize lets a newer plugin detect an older server before touching fields it should not: treat sizeof(CsPluginApi) smaller than expected as a signal to degrade gracefully instead of crashing.
