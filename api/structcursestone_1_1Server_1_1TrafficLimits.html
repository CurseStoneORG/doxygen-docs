Detailed Description

Traffic pacing limits (cursestone.yml traffic.

* keys).

Per-source rate budgets enforced inside the RakLib session manager: a per-sweep datagram budget per endpoint, per-second budgets for the unconnected packet classes (pings, handshake requests, fresh sessions), a concurrent-session cap per source IP, and an escalating pacing hold for sources that keep violating their budgets. See the traffic pacing block comment in src/network/raklib/SessionManager.h for the mechanics.
