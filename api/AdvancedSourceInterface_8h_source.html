40 // Wire-order classes — one RakNet ordering channel each. The packet mix a
41 // 0.15 client tolerates is strict about some sequences and indifferent to
42 // others, so every outbound send declares which class it belongs to:
43 //
44 // - Unordered → RELIABLE on channel 1. Everything whose inter-packet
45 // order the client does not care about (movement, entity updates,
46 // block events, chat). A lost datagram only retransmits itself.
47 //
48 // - LoginOrdered → RELIABLE_ORDERED on channel 0. The login/spawn
49 // handshake (PlayStatus → StartGame → SetTime → ...): the client
50 // walks off and hangs if these arrive reordered, and the sequence is
51 // short, so a retransmit-then-unblock here is never observed.
52 //
53 // - ChunkOrdered → RELIABLE_ORDERED on channel 2. The chunk stream:
54 // FullChunkDataPacket plus the BlockEntityDataPackets of its tiles.
55 // The 0.15 client rebuilds a chunk when its payload arrives and
56 // destroys every block actor it holds for that chunk, so a tile
57 // packet processed BEFORE its chunk binds an actor the very next
58 // datagram wipes — the chest then renders invisible and cannot open.
59 // Plain RELIABLE delivery does NOT prevent this: real Wi-Fi/LTE
60 // paths reorder UDP datagrams constantly, and a chunk payload spans
61 // 2-30 of them while each tile NBT fits in one. Sharing one ordered
62 // channel turns tile-after-chunk into an on-the-wire guarantee
63 // instead of a same-thread enqueueing accident that only holds on a
64 // loopback network.
65 enum class WireStream : uint8_t {
66  Unordered = 0,
67  LoginOrdered = 1,
68  ChunkOrdered = 2,
69 };

71 class AdvancedSourceInterface : public SourceInterface {
72  public:
73  // Send a packet (already-encoded bytes including the leading ID byte)
74  // to the player identified by `ip`:`port`, routed through the given
75  // WireStream (see the enum above for the reliability/channel table and
76  // the client-side sequences each stream protects).
77  // `data` is taken by value: callers that just built the buffer
78  // (the batch writer) can std::move it in, so the wire payload
79  // transfers into the outbound queue without a heap copy per send.
80  virtual void sendRawPacket(const std::string& ip, uint16_t port,
81  std::vector<uint8_t> data,
82  WireStream stream = WireStream::Unordered) = 0;
83  // Close a session immediately, optionally sending a DisconnectPacket first.
84  virtual void closeSession(const std::string& ip, uint16_t port,
85  const std::string& reason = "") = 0;
86 };
