24 // DBEngine — a self-contained, real-format LevelDB engine.
25 //
26 // Creates and maintains the same file set the real MCPE client produces
27 // inside `<world>/db`: CURRENT, LOCK, MANIFEST-<n>, <n>.log (WAL) and
28 // <n>.ldb (tables) — no external library involved. Worlds written by the
29 // real device (snappy tables) and by PocketMine (zlib tables) open here,
30 // and the files this engine writes are ordinary LevelDB tables any reader
31 // of the format understands.
32 //
33 // Layout it maintains:
34 // db/CURRENT -> "MANIFEST-000002\n"
35 // db/LOCK -> flock()ed exclusively while open
36 // db/MANIFEST-<n> -> log-format file holding the full VersionEdit
37 // db/<n>.log -> WAL of batches not yet flushed to a table
38 // db/<n>.ldb -> SSTables (level 0 from flushes, level 1 from
39 // the periodic full compaction)
40 //
41 // Durability contract (what a server actually needs):
42 // * every accepted batch is in the WAL before put_batch() returns
43 // (process-crash safe),
44 // * flush() turns the memtable into a table + rotates the WAL (the
45 // manifest is rewritten and CURRENT swapped atomically before the old
46 // WAL is deleted, so a crash in between replays, never loses),
47 // * full compaction merges every table when level-0 count crosses the
48 // trigger, keeping the file set bounded.
49 //
50 // Threading: one internal mutex. The provider funnels writes through its
51 // background worker; reads may come from the main thread concurrently.
