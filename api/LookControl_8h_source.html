24 // LookControl — the head rotation control.
25 //
26 // Port of <minecraftpe/impl/entity/ai/LookControl.cpp> (MCPE 0.8.1
27 // decompile). Goals call setLookAt to request a facing; tick() turns
28 // the head toward it at the requested speeds, zeroes the pitch when no
29 // look target is set, and clamps the head within +/-75 degrees of the
30 // body while the navigation is moving.
31 //
32 // Adaptation: the era LookControl consumed its request in one tick
33 // (isLooking reset at the top of tick()). CurseStone ticks the goals on
34 // a cadence (full tier: every tick; reduced tier: every 4th), so the
35 // request is held for a few ticks after it lands — kRequestHoldTicks —
36 // and expires when the goal stops refreshing it. Without the hold, the
37 // head would snap back onto the body between two goal ticks.
