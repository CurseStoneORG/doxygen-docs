24 // Goal — one composable behavior of a mob brain, plus the MobContext
25 // snapshot a goal is allowed to read. Goals are pure decision logic:
26 // they never touch the World, players or packets. They read the
27 // immutable MobContext and write movement intent into their MobBrain;
28 // the MobAIManager is the only component that turns intent into world
29 // mutations (see docs/MOB_AI.md).
