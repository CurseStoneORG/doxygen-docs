24 // Goal — one composable behavior of a mob brain.
25 //
26 // Port of <minecraftpe/impl/entity/ai/Goal.cpp> (MCPE 0.8.1 decompile,
27 // oldminecraftcommunity). The class shape is the era one: a goal carries
28 // the control flags it claims (move / look / jump), the GoalSelector
29 // decides when it runs, and the goal drives the mob through the controls
30 // (LookControl::setLookAt, PathNavigation::moveTo, JumpControl::jump).
31 //
32 // Adaptation: the era methods take no arguments because every goal held
33 // its holder pointer from the constructor. Here the Mob facade the brain
34 // owns is passed through the selector instead, so goal objects never
35 // store a pointer that can outlive the bound record.
